## Описание

WPF-приложение (.NET Framework) для учёта личных платежей с разграничением ролей (Пользователь / Администратор).

### Основные возможности

- Авторизация и регистрация с хэшированием паролей (SHA-256)
- Защита от брутфорса (блокировка + капча после 3 неудачных попыток)
- Страница пользователя: просмотр, поиск, сортировка, фильтрация своих платежей
- Страница администратора: полный CRUD, графики, экспорт отчётов (.docx / .pdf / .xlsx)
- Смена пароля
- Смена темы (светлая / тёмная) с сохранением выбора
- Единый стиль по руководству (Open Sans + Pantone-палитра)
